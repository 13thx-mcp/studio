1. Persist explicit update-check request and per-component terminal outcomes from JoinSet results. Preserve stale cached latest as stale; GET inventory is not an update check.
2. Record prepare/stage from validated artifact receipt (provider/version/platform/content evidence only). Prepare failure is not an attempted installation. Apply admission links to its prepared history and original M5 transaction ID without enabling SQL resumption.
3. Hook MCP, Gateway and Fleet phase/outcome branches outside mutexes. Record verification evidence before cleanup if useful, but do not emit Completed before the existing authoritative terminal point. For these owners, cleanup that currently fails the operation still prevents a fabricated Completed.
4. For Tunnel upgrade/reinstall/rollback/recovery capture typed validated terminal journal receipts before existing deletion. Target/source same version may have different content identities. Bounded post-safe-state flush must not retain/change journals solely for audit.
5. Normalize failed-with-rollback_succeeded and rolled_back into a failed target install plus verified restoration. LKG records a verified artifact with proof scope; do not infer from requested version or generic inventory health.
6. For Studio use persisted readback revision, correlate old/new process runs, and observe Fleet-only terminal results after listener readiness with the finite known-transaction observer. Missing revisions stay partial, and a successful health endpoint is not terminal proof.
7. On restart retain nonterminal volatile transactions as interrupted/indeterminate history, not actionable staged work. Replay validated source records idempotently; bootstrap imported terminals do not increment new M6 installs.
