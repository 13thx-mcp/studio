## Scope

M8.3 enables bounded automatic release observation and verified preparation only.

Policy actions are structurally limited to:

```text
manual            -> no action
notify-only       -> ObserveOnly
auto-prepare      -> PrepareOnly
auto-update-safe  -> PrepareOnly   # until M8.4
```

There is no activation action in M8.3.

## Implemented

- one concurrent update-check batch;
- `SystemAutomation` audit actor through immutable M6 schema migration v2;
- desired exact target precedence over latest stable;
- fresh successful provider check required before latest is automatic authority;
- no downgrade or same-version automatic reinstall;
- notify-only returns before staging/runtime mutation;
- auto-prepare calls existing component `prepare()` owners and requires `Staged`, artifact identity and staging ownership identity;
- current-process prepared references bind transaction/staging/fingerprint/policy identity;
- previous-process prepared authority is discarded on Studio restart;
- safe ready-staging TTL cleanup with current-process protection;
- bounded retained-ready staging byte budget and symlink/special-file rejection;
- source hygiene observation: runtime-only / clean / dirty / conflict / unavailable;
- update-check failure circuit with cooldown, single half-open probe and success reset;
- M8.2 restart scheduling and M8.3 update scheduling coexist in one AutomationController.
