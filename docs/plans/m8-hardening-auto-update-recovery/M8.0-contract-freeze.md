## Blocking questions — resolved

- **Durable Unknown ordering:** ADR 0040 requires hold fsync/commit before terminal unsafe Unknown; persistence failure disables automation safety rather than replaying.
- **Targeted child identity:** ADR 0041 reuses global drain and proves target child generation/catalog plus component running identity before resume.
- **Recovery scratch ownership:** ADR 0044 preserves owner-specific generic/Fleet/Tunnel/Studio/reconciliation recovery material; generic cleanup is allowlist-only.
- **Audit service:** ADR 0037 extracts an internal service around existing `HistoryHandle::admit_operation` / `finish_operation`; HTTP headers remain presentation only.
- **Externally managed runtime:** only components with an explicit trusted activation adapter are auto-activation targets; unmanaged/external children remain excluded.
- **Fleet policy authority/stale policy:** ADR 0043 makes host schema v3 authoritative and blocks old-process destructive automation after managed Studio config changes.
- **Prerelease release control:** ADR 0045 keeps `v0.8.0-beta` on the guarded release-evidence path.
