## Failure semantics

- render/check failure may open circuit after threshold;
- managed-safe apply failure invokes existing rollback then counts failure;
- rollback failure immediately blocks automation;
- unmanaged/local/broken/unknown state is a deferral/operator condition, never an automatic mutation candidate;
- timer ticks cannot "adopt" unknown state.
