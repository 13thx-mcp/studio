## Fault matrix

- provider unavailable/malformed;
- coordinator busy;
- Gateway control unavailable/old;
- post-dispatch unsafe unknown;
- hold-store ENOSPC/corruption;
- child restart failure;
- staging tamper;
- disk budget/ENOSPC;
- dirty source;
- maintenance window closes;
- component stop/start/health failure;
- rollback failure;
- Studio crash at each update phase;
- Gateway crash with open hold;
- repeated reconciliation failure;
- diagnostics write failure.

## Soak

Measure/assert:

- controller task count;
- overlapping evaluations;
- retry frequency;
- state file size;
- open/retained hold count;
- staging directory bytes/count;
- recovery artifact count;
- history growth/retention behavior;
- child restart counts/circuit behavior;
- no mutation replay.
