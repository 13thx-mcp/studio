# M8.1 — Automation Foundation and Durable Policy State

**Status:** VERIFIED / CLOSED — qualified at production commit `2718ab251d1874914bc00ea8e6d288f06689ed4c`; see [M8.1 qualification](M8.1-QUALIFICATION.md).

## Objective

Create the single Studio automation owner and durable non-secret policy state without enabling automatic activation.

## Primary source areas

- `src/config/`
- new `src/automation/`
- `src/update/mod.rs` coordinator introspection
- shared audit/admission boundary currently in API/storage
- `src/main.rs` startup/shutdown integration

## Contracts

- additive manual defaults;
- one AutomationController;
- bounded timers;
- state.json schema v1;
- UTC maintenance windows;
- persisted backoff/circuit;
- shared audit admission;
- no catch-up queue.

## Sequence

1. Config schema/types/range validation.
2. State store with atomic durability/fault tests.
3. Fake clock abstraction for tests.
4. ScheduleEngine.
5. failure/deferral/circuit state machine.
6. coordinator snapshot.
7. shared operation admission.
8. controller startup after readiness grace.
9. graceful cancellation.

## Failure semantics

Corrupt/future state: API/manual operation remains available where safe; background destructive automation is disabled with explicit blocker.

History admission unavailable: no discretionary automatic mutation.

## Exit criteria — PASS

M8.1's portions of R01–R08, R47 and R52–R54 are qualified. R53 remains active for the later end-to-end automation producer/UI proof in M8.7, but the shared `OperationService` boundary is already used by both API and AutomationController. Controller performs no automatic prepare/apply in M8.1.
